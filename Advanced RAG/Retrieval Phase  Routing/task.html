Description

We’ve used an LLM to decompose a user’s query into multiple queries that capture the user’s intent. We’ve also used HyDE and used context ranking techniques. This enhanced our retrieval mechanism making it possible to retrieve all the relevant chunks needed to answer a user’s query. However, we have more than one data source. We’d like a way to translate the user’s query to a format more suitable for the data source. This will allow us to retrieve data from multiple data stores.

We have both a relational database as well as a vector store for different types of data. We need to ensure that if records from a relational database are needed, the query is translated into an SQL statement as well as raw input for a general query. Once we obtain contexts from both sources, we can combine them all and pass them to the LLM.

There are multiple way you can implement routing. The most efficient one would be using LangChain tools. The LLM will determine which tool, or combination of tools, to use depending on the user’s query and pass the right parameters to it. Once you retrieve all contexts, combine them and pass them to the LLM, along with any additional instructions and chat history, to get the final response.

To make it easier to create an accurate database query command, ensure to specify the database schema in the docstring for the database query tool.

Objectives

Here is what you need to do at this stage:

  • Create two tools to interact with the data stores depending on the user’s query. The LLM should automatically translate the user’s query into a format more suitable for the data store to use;

  • Once a query is issued, the LLM should select the appropriate data store, pass the right parameters, and retrieve the appropriate context. Context could either be chunks from a vector store or order details from the database, or both;

  • Print the contexts retrieved from the data stores;

  • Pass the retrieved contexts to the LLM and print the final response;

> I need to return something.

I’m here to help you with your return! However, I currently don't have specific information regarding the return process. Please check our website or contact customer support for detailed instructions on how to return your item.
